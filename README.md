A program that copies a pre-rendered front-page poster summing up the world news of Wednesday 18 November 2026 — the Shenzhen trilateral summit, the Crimea bridge strike, the Gulf escalation, and the US measles and Senate stories — to /output/entry.png. The poster is drawn by render.py (Pillow, build-time only); main.py itself uses only the Python standard library.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
